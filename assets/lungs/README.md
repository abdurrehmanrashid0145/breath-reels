# Lung picture sets

Each folder here is one set of four lung pictures, worst to best:

```
assets/lungs/<set-name>/1.png   wrecked / smoker lungs (top)
assets/lungs/<set-name>/2.png   half damaged
assets/lungs/<set-name>/3.png   healthy
assets/lungs/<set-name>/4.png   strong / cute flexing lungs (bottom)
```

PNG (transparent background), WebP, JPG or SVG all work; square-ish images look best.
As soon as at least one complete set exists, reels pick from these sets (rotating between them)
instead of the built-in cartoon lungs.
